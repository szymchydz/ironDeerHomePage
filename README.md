# IronDeer – Strona internetowa
Oficjalna strona internetowa projektu **IronDeer** dostępna pod adresem:  
👉 https://irondeer.pl
---

## 📌 Opis projektu
Strona internetowa zaprojektowana i wdrożona od podstaw. Projekt skupia się na prostocie, czytelności oraz wydajności.
Została przygotowana jako w pełni responsywna witryna, dostosowana do urządzeń mobilnych oraz zoptymalizowana pod kątem SEO.
---

## 🛠️ Technologie
- HTML5  
- CSS3  
- JavaScript  
- PHP (obsługa formularza kontaktowego)  
---

## ⚙️ Funkcjonalności
- Responsywny design (mobile-first)  
- Formularz kontaktowy (PHP)  
- Optymalizacja SEO (sitemap.xml, robots.txt)  
- Konfiguracja serwera (.htaccess)  
- Szybkie ładowanie i lekka struktura  
---

## 📁 Struktura projektu
/assets # zasoby (obrazy itp.)
/js # skrypty JavaScript
index.html # główna strona
style.css # style
send.php # obsługa formularza
.htaccess # konfiguracja serwera
---

## 🚀 Uruchomienie lokalne
1. Sklonuj repozytorium:
   git clone https://github.com/szymchydz/ironDeerHomePage.git
2. Otwórz `index.html` w przeglądarce  
*(dla formularza PHP wymagany serwer lokalny, np. XAMPP)*
