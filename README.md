## 📌 Project Description
A fully custom-designed and developed website. The project focuses on simplicity, clarity, and performance. 
The site is fully responsive, optimized for mobile devices, and prepared with SEO best practices in mind.

## 📁 Project Structure
- /assets      # assets (images, etc.)
- /js          # JavaScript scripts
- index.html   # main page
- style.css    # styles
- send.php     # contact form handler
- .htaccess    # server configuration
---

## 🚀 Local Setup
1. Clone the repository:
git clone https://github.com/szymchydz/ironDeerHomePage.git

2. Open index.html in your browser
(PHP contact form requires a local server, e.g., XAMPP)
